\# ATM vs Barcelona: Football Match Prediction



\## Project Overview

A Machine Learning project that predicts football

match outcomes using a Random Forest Classifier.



\## Machine Learning Model

\- Algorithm: Random Forest Classifier

\- Number of Trees: 400

\- Training Samples: 560

\- Testing Samples: 140



\## Features

\- Recent team performance

\- Goals scored and conceded

\- Head-to-head performance

\- Home advantage



\## Prediction Classes

\- Atletico Madrid Win

\- Draw

\- Barcelona Win



\## Model Evaluation

\- Test Accuracy: 35%

\- Evaluation: Precision, Recall, F1-score

\- Confusion Matrix



\## Dataset

The project uses a synthetic educational dataset

containing 700 records.



\## Important Limitation

The dataset is synthetic and does not represent

actual historical La Liga match results.



The prediction is an educational demonstration,

not a reliable real-world football forecast.
